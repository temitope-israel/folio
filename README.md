# Folio — My Personal Portfolio

> "I build things that work." — Temitope Israel Omoniyi


## Tech Stack

**Frontend**
- React 19 + TypeScript
- Vite (build tool)
- Tailwind CSS v4
- Framer Motion (animations)
- Shadcn UI (component library)
- Lenis (smooth scroll)
- React Hook Form + Zod (form validation)

**Backend**
- Node.js v22 + Express.js + TypeScript
- Nodemailer (email)
- CORS, Helmet, express-rate-limit (security)

**Database**
- PostgreSQL 18.3 (local)
- Prisma ORM

## Features
- Working contact form (emails + database storage)
- Page visit analytics
- Password-protected admin dashboard
- Preloader, custom cursor, smooth scroll
- Fully responsive, mobile-first design

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```
